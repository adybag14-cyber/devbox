# Devbox 0.9.35

This unpublished candidate was superseded by 0.9.36 to preserve document-level
status evidence alongside modal observations.

This candidate combines the native efficiency and browser changes from the
unpublished 0.9.32–0.9.34 candidates, with Chrome Bridge 0.2.11. The server
remains C++23. No runtime dependency or Chrome permission is added.

Transparent ARIA dialogs that do not intercept input no longer replace ordinary
page observations, including zero opacity on an ancestor or shadow host. The
bounded fallback check preserves native modal blockers and dialogs that actually
intercept input. Empty or whitespace-only dialogs remain insufficient content
until text or controls appear; short dialogs with real controls remain usable.

The active-dialog reporting cap, covering-modal selection, root and nested
scrolling, tab-bound grant/revocation, and explicit until-revoked grants are
retained. Text responses now expose the limitation that descendant shadow-root
text can be omitted and direct callers to the screenshot for the composed view.

Native cache byte accounting, streamed research signatures, Windows directory
validation, UTC formatting and bounded ASCII text slicing are included. Source-
bound component measurements and their limitations remain in the relevant docs;
they do not promise equivalent network, model-latency or process-RSS reductions.

The reviewed jose 6.2.14 and rmcp 3.8.0 lockfile updates apply to the retained
reference implementations. All required native platform, bridge, retained-runtime,
security, installer and packaging checks must qualify this combined source before
publication. Earlier candidate heads, artifacts and production rollback files
are preserved.
