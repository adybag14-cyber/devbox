# Devbox 0.9.34

This unpublished candidate was superseded by 0.9.35 after additional visibility
and dialog-readiness review findings were reproduced and corrected.

This candidate combines the native efficiency and browser improvements from the
unpublished 0.9.32/0.9.33 candidates with the final modal-selection corrections.
The server remains C++23; the optional Windows Chrome Bridge is version 0.2.10.
No runtime dependency or Chrome permission is added.

Native and bridge observations keep an active modal selectable after the
eight-entry reporting cap. A hit-tested covering modal takes precedence over
focus in an obscured lower dialog. Selection retains only three candidate
references alongside the bounded report. Existing element/root, text, HTML,
control, request-time and observation-freshness limits remain in effect.

The release also includes exact web-cache byte accounting, streamed research
signatures, faster Windows directory validation, native UTC formatting, and
bounded ASCII output slicing. Component measurements, unchanged-output evidence
and timing limitations are retained in the related docs and benchmark data.
They do not claim equivalent improvements in network or model latency.

Chrome Bridge supports explicit until-revoked grants, individual revocation,
dialog-aware observations and popup actions bound to the displayed tab and
origin. Worker shutdown remains a documented end to in-memory access. Existing
qualified artifacts and installed versions are retained; no earlier release is
overwritten or relabelled.

The reviewed jose 6.2.14 and rmcp 3.8.0 updates remain limited to the retained
JavaScript and Rust reference implementations. The full hosted native, bridge,
retained-runtime, security, installer and packaging gates apply to this final
combined source before publication.
