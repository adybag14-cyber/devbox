# Devbox 0.9.36

The C++23 browser preserves the document text used for challenge and error
classification while reporting active modal text separately. An overlay cannot
hide a challenge phrase from page-status detection. Dialog readiness uses
observed viewport text or opaque hit-tested controls, not the presence of a
dialog object or unpainted control metadata alone.

ARIA dialogs narrow observation scope only with hit-test evidence. Native modal
elements remain fallback blockers. The eight-entry report and three selection
references remain bounded, as do node/root, text, control and request limits.
Chrome Bridge 0.2.12 also correctly distinguishes exact text-budget completion
from actual truncation and retains ordinary document context after modal text.

The candidate includes the native research, cache, UTC, directory and bounded
ASCII slicing improvements, explicit until-revoked grants, tab-bound grant and
revocation, and the reviewed retained-runtime dependency updates. No runtime
dependency or Chrome permission is added.

Nested shadow-root text and native control enumeration remain explicitly limited;
returned notes identify when callers should use the screenshot. The independent
extension can enumerate open-shadow controls. This release does not claim full
composed-DOM or universal site compatibility.

All source-bound benchmark data and limitations are retained. Required platform,
security, installer, packaging, bridge and retained-runtime gates apply to this
combined source before publication; earlier candidates and artifacts are not
overwritten or relabelled.
